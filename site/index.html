Tus tareas viven
en tu terminal

tasktui es un gestor de tareas hecho para el teclado: una TUI y una CLI en Go, captura rápida en lenguaje natural y un servidor tuyo que comparte las mismas tareas con el navegador, el celular y Claude.

  • Un binario en Go
  • Markdown o SQLite
  • MCP para Claude
  • Licencia MIT

Escribe como hablas

Una sola línea lleva fecha, hora, prioridad, proyecto, etiquetas y repetición. tasktui la entiende mientras escribes, en la terminal, en la web y por la API.

Un servidor, todas tus pantallas

Un solo servidor es la fuente de verdad y todos los clientes hablan la misma API. La lógica vive en un núcleo compartido, así que una tarea se interpreta igual en todas partes.

Instálalo en minutos

Empieza solo con la terminal y, cuando quieras tus tareas en más lugares, levanta el servidor.

# Requiere Go 1.27 o superior
❯ go install github.com/alfonsoHR98/tasktui/cmd/tasktui@latest
❯ tasktui demo          # pruébalo con tareas de ejemplo
❯ tasktui               # tus tareas, como Markdown en ~/.local/share/tasktui

Sin servidor, cada proyecto es un archivo .md compatible con Obsidian Tasks. Apunta la carpeta a tu vault y las ves también en Obsidian.

❯ git clone https://github.com/alfonsoHR98/tasktui.git && cd tasktui
❯ cp .env.example .env    # pon un API_TOKEN: openssl rand -hex 24
❯ docker compose up -d --build
❯ tasktui server connect http://127.0.0.1:8787

Un contenedor con la API, la página web y el MCP; las tareas viven en un archivo SQLite dentro de un volumen. Para usarlo fuera de casa, la guía explica HTTPS con Caddy, Cloudflare Tunnel o Tailscale.

❯ git clone https://github.com/alfonsoHR98/tasktui.git && cd tasktui
❯ make server
❯ API_TOKEN=$(openssl rand -hex 24) DATABASE_PATH=./tasktui.db ./tasktui-server

El servidor es un solo binario en Go puro, sin cgo: corre igual en un VPS, una Raspberry Pi o tu Mac.

Tuyo de verdad

Sin cuenta, sin nube ajena. Tus tareas son texto que puedes leer, respaldar y mover.

  • Exporta cuando quieras. tasktui export escribe todo a Markdown y /api/export lo entrega en JSON.
  • Una persona, un token. Es una herramienta personal, no un servicio multiusuario.
  • Funciona sin internet. En modo remoto ves la última copia y los cambios se rechazan con un aviso en vez de perderse.
